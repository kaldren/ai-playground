# AI Playground

A playground for experimenting with AI-related projects in both Python and .NET.

## Structure

```
ai-playground/
├── dotnet/             # .NET projects
│   └── AIPlayground.slnx  # Solution file
└── python/
    ├── learn/          # Focused language and framework exercises
    └── projects/       # Standalone Python projects
```

- **dotnet/** — Contains the `AIPlayground` solution and any .NET projects/experiments.
- **python/learn/** — Contains small, topic-focused Python examples.
- **python/projects/** — Contains independently configured Python projects.
